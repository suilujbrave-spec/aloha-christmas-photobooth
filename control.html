Photo Backup Manager

The backup utility runs locally on the event laptop and cannot be launched directly by GitHub Pages.

C:\AlohaBackupUtility\start-backup.bat
  1. Open C:\AlohaBackupUtility in File Explorer.
  2. Double-click start-backup.bat.
  3. Use Start Automatic Mode during the event.
  4. Keep OneDrive showing Up to date.
